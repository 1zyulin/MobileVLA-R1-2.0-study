# 模板：单篇精读 / 周三报告 / 实验记录

复制相应段落到 `reading-2026/notes/YYYY-MM-DD-paper-slug.md`、`reading-2026/reports/YYYY-MM-DD-weekly.md` 或 `reading-2026/experiments/YYYY-MM-DD-topic.md`。先写证据，再写推断。

## A. 单篇精读

```markdown
# 论文标题
- 学习日期：
- 论文：arXiv/DOI 链接；版本；首次发布日期；是否正式发表（已核实/未知）
- 代码：作者仓库及对应提交；是否已有可执行代码/数据/权重
- 研究问题（一句话）：
- 与 MobileVLA-R1 2.0 的联系：

## 核心思想（自己解释）
## 输入—模块—输出（Mermaid 或 ASCII 图）
## 关键公式与符号（注明论文节、式号；复述而非直接复制）
## 训练数据/监督/奖励来源
## 实验设置、指标、作者报告结果（写表号和数据划分）
## 自己能验证什么、尚未验证什么
## 代码核验：路径、接口、输入形状、依赖与许可
## 学习收获（至少3点）
## 尚不明白的问题（至少2点）
## 下一步：一个不依赖猜造数据的最小实验
```

## B. 周三学习报告（每周至少两篇不同论文）

```markdown
# 第X周论文学习报告（YYYY-MM-DD，周三）
- 本周目标：
- 本周阅读论文 A：[标题](论文链接)
- 本周阅读论文 B：[标题](论文链接)
- 完成部分：各自读到哪一节；待读部分：

## 论文 A：核心思想、方法与公式
## 论文 B：核心思想、方法与公式
## 两篇对比（任务、模态、推理方式、action 输出、RL、评测）
## 和 MobileVLA-R1 2.0 的三点关系
## 代码/实验实践：输入、环境、操作、实际输出及证据
## 存在问题：哪些是作者表述，哪些是我确认的
## 本周学习收获
## 下周安排
```

## C. 实验复现记录

```markdown
# 实验名称
- 日期 / 目的 / 假设：
- 来源：论文版本、作者代码提交、权重版本与校验、数据版本和许可证
- 环境：操作系统、Python/PyTorch/CUDA、GPU、显存
- 输入与数据划分：样本数、单位、坐标系、缺失项
- 命令与重要参数（不含密码/令牌/内网地址）：
- 实际输出、保存位置（用脱敏相对路径）、运行时间、峰值显存：
- 评测指标与分母 / 重复次数 / 随机种子：
- 结论：完成 / 失败 / 未执行（必须与证据一致）
- 与作者结果的差异及不可对齐因素：
- 下一步：
```

**写作原则：** 不编造训练结果、会议录用、数据指标、代码完成度；缺少依据写“待核实”。公共仓库不上传服务器密码、内部网络地址、私人数据或大模型文件。
