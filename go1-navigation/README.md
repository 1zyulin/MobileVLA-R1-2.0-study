# Go1 具身语义导航与动态避障｜16 周学习与复现规划

> 版本：v1.0；制定日期：2026-10-28；执行窗口：2026-11-02 至 2027-02-21（16 周）。
>
> 状态：**这是计划，不是已完成的实验**。课题定位：面向四足机器人的开放词汇语义导航与人群动态避障。
>
> 目标机器人：Unitree Go1（具体版本、机载计算、传感器与 SDK 待核查）；实验平台：共享 RTX 5090。不得声称已在 Go1 或 5090 上完成以下方案的整套复现。

## 1. 最终目标与不做的事

最终实现一套平地室内导航原型，能够：
1. **找物体（ObjectNav）**：根据“找红色椅子”搜索目标，在其附近安全停止。
2. **找人（Person Search / Follow）**：寻找符合描述的人，持续跟踪目标；“指定个人识别”另需授权参考信息及重识别模块，不等于普通行人检测。
3. **找地点（PlaceNav / VLN）**：理解“去实验室门口、302 房间”等指令，结合已知地图/视觉语义定位导航。
4. **动态避障（Human-Aware Navigation）**：遇到行人时识别、跟踪、预测风险，并执行减速、等待、绕行或停车。

**边界**：本项目首先研究平地语义导航和避人，不以跳跃、爬楼梯、强化学习足端动作作为第一目标；高层导航与 Go1 底层稳定行走控制解耦。首次闭环必须在仿真中完成，不能用“仿真无碰撞”替代真机安全证明。

## 2. 学习规则与时间预算

- 每周 **2 篇不同论文**（至少重点研读问题/方法/实验/局限；周三提交双论文周报）。对旧论文再次研读须有不同的公式、算法或代码核查问题。
- 周一理解 A 论文；周二理解 B 论文；周三提交周报；周四源码/最小实验；周五更新 GitHub 证据与问题清单；周末可补实验。
- 建议每周 10–14 小时；考试、导师安排和共享 GPU 冲突时可延长总周期，不盲目赶进度。
- **与已有计划协调**：2026-11-02 至 12-13 的 6 周，直接沿用仓库 [原 8 周阅读日历](../reading-2026/ROADMAP-8-WEEKS.md) 中对应论文；**不要求再额外读两篇**。将本项目的每周技术实践与旧周报合并。12-14 后切入本路线专题论文。
- 任何周报注明：论文作者的成绩、本地实测结果、尚未验证的计划，三者不得混写。

### 每篇重点论文的统一学习结构（3 阶段、共 6 节）

| 阶段 | 节 | 学什么 | 交付物 |
|---|---|---|---|
| I 认识论文 | 第 1 节 | 题目、摘要、问题、输入输出和核心贡献 | 一句话解释 + 框架图 |
| I 认识论文 | 第 2 节 | 相关工作、任务定义与基线 | 2–3 篇对照文献 |
| II 拆解算法 | 第 3 节 | 网络/模块、信息流、坐标与动作接口 | 自绘流程图 |
| II 拆解算法 | 第 4 节 | 损失/奖励/优化/规划公式与算法 | 关键公式逐项解释 |
| III 验证复现 | 第 5 节 | 数据集、指标、消融、失败案例 | 实验对照表 |

**第一节总是先用通俗语言概括整篇论文**，再讲细节。代码讲解要交代每条命令的用途、主要参数、预期结果与风险。

## 4. 技术栈与仿真策略

| 模块 | 优先方案 | 不确定性和退路 |
|---|---|---|
| 语义目标搜索 | ApexNav（基线）→ VLFM / VLN-Game（对照） | 论文代码中目标检测/仿真依赖可能较旧；先固定一个可运行分支 |
| 仿真场景 | Habitat + 已获授权的 HM3D | 仅在授权到位后下载；不同 HM3D 版本的 scene 和 episode 必须对齐 |
| 动态行人 | 简单可控的动态场景 + 传统局部规划基线 → ComposableNav | Habitat ObjectNav 默认并不提供你所需的所有动态行人机制，需单独引入 |
| 高层语义/任务分配 | 类别检测、语言目标解析、VLMaps | 不需要先训练整套大型 VLA；分离语义决策和碰撞监控 |
| 行人跟踪 | 检测器 + 多目标跟踪（如 ByteTrack） | 丢帧、遮挡、身份交换要记录；指定个人需要合法且可靠的参考特征 |
| 真机控制 | Go1 对应版本的高层控制 SDK/ROS 桥接 | 检查 Go1 Edu/Air/Pro 等具体硬件和通讯协议，不能默认兼容 Go2 |
| RTX 5090 | 单独 Conda 环境 + 支持 Blackwell 的 PyTorch/CUDA 构建 | VLFM / NaVILA 的旧版 torch、Habitat 或 CUDA 扩展不保证可直接运行；禁止改动共享系统驱动 |
| 可选仿真备选 | 支持 5090 的 Isaac Sim / Isaac Lab + Go1 资产 | 更换仿真器后**不是**原论文的同协议结果，必须明确标记 |

**共享服务器要求**：不覆盖已有 Conda 环境、不杀他人 GPU 进程、不修改系统驱动。每次运行前查看资源；根据可用资源限制 batch / 并发，实验超时主动退出。

## 5. 统一评测协议（W06 确定，W15 不再事后更改）

| 目标 | 指标 | 说明 |
|---|---|---|
| 物体搜索 ObjectNav | SR、SPL、路径长度、用时 | 任务成功需要明确目标识别及到达半径 |
| 地点导航 PlaceNav | SR、终点误差、导航耗时 | 已知地图和未知地图分别报告 |
| 找人 Person Search | 目标检出率、跟踪中断/ID 切换、跟随完成率 | 指定人时独立记录授权身份匹配准确性 |
| 动态避障 | 碰撞率、最小人机距离、近失事件、停车延迟 | 测静态、迎面、横穿、突然出现、遮挡场景；报告失败案例 |
| 系统整体 | 三类任务分别的 SR、平均推理/控制延迟、GPU 峰值显存 | 统计所有尝试，不只挑成功视频 |

固定场景、训练/测试划分、任务数、随机种子、障碍生成规则、目标成功判据。基线与改进版保持一致；任何替代条件必须列在实验报告中。

## 6. Go1 真机安全门槛（全部满足才考虑上机）

- [ ] 确认 Go1 型号、机载系统、网络接口、可用摄像头/雷达，验证坐标系与实际量程。
- [ ] 在仿真通过静态、行人动态、传感器遮挡/掉线及异常停止测试。
- [ ] 具备人工遥控急停、独立速度限制、命令超时自动停、可视监护和隔离测试区域。
- [ ] 确认高层 SDK 的速度单位、方向及动作边界；先空载/限位实验，再空旷无人场地低速测试。
- [ ] 有人环境试验须获场地管理者同意、取得相关参与者知情同意，并由现场人员监护；“不撞人”不是任何学习模型能保证的绝对属性。
- [ ] 不从未验证的高层语言模型直接输出关节扭矩；不要在实验室有人通行时进行无监护自主实验。
