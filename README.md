## 我们在做什么

研究目标是检验：模型能否结合机器人看到的场景和人类指令，生成推理，并通过训练过的动作模块给出任务层运动指令。学习目标是理解并亲手核查“素材 → 样本 → 参数更新 → 模型输出 → 独立评测”这条链。

```mermaid
flowchart LR
    A[论文与源码] --> B[环境和权重兼容]
    B --> C[真实数据与标注对齐]
    C --> D[两步 RGB 训练验证]
    D --> E[扩大监督训练]
    E --> F[动作监督与 GRPO]
    F --> G[离线及闭环评测]
```

图中后续阶段是计划，不表示已经运行。RGB 小样本验证只检查一条真实轨迹的图文训练流程；完整动作策略还需要动作监督、模态准备和独立评测。
